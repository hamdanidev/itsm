## Langkah

1. Nyalakan PocketBase sementara dengan direktori data kosong.
2. Buat tenant, unit, pengguna, tiket, dan satu lampiran.
3. Buat backup ZIP, lalu hentikan server sumber.
4. Ekstrak ZIP ke direktori data target.
5. Nyalakan PocketBase dari hasil restore.
6. Verifikasi health, login pengguna, tiket, lampiran, dan jumlah record.

## Keterbatasan / tindak lanjut

- Dataset sintetis dan kecil; bukan bukti kompatibilitas data produksi.
- Belum menguji restore dari salinan off-host/enkripsi.
- Belum menguji restore lewat Admin UI dan pergantian volume Docker.
- Belum menguji ukuran data besar, lampiran banyak, atau versi PocketBase berbeda.
- **Wajib:** ulangi drill di staging dengan backup produksi sebelum pilot, lalu
  catat hasilnya di folder ini.
- Aktifkan alert backup (S0-6) agar backup yang gagal/basi tidak baru diketahui
  saat restore.
